# 내 할 일 추가 스킬

사용자가 적은 할 일을 `{기업, 할 일, 마감일}`로 정리해 칸반보드 `state.todos`에 추가한다.

## 실행 흐름

1. **정리**: 입력을 항목별로 나눈다. 한 줄에 여러 개면 각각 분리한다.
   - `company`: 칸반보드 기업명(예: 삼성전자). 특정 기업 업무가 아니면 `공통`(팀·여러 교육에 걸친 업무) 또는 `기타`(그 외)를 넣는다. 사용자가 "공통"/"기타"라고 적었으면 그대로 쓰고, 애매하면 생략한다.
   - `title`: 기업명·마감 표현을 뺀 할 일 본문. 짧고 명확하게 (예: "TSP 일정확인").
   - `due`: `YYYY-MM-DD`. "10월 1일", "내일", "금요일", "다음주 화요일" 등은 오늘 날짜 기준으로 계산한다. 연도가 없으면 가장 가까운 미래 날짜. 마감이 없으면 생략.
   - 날짜가 애매하면(예: "월말", "다음 교육 전") 사용자에게 묻는다.
2. **담당자**: 기본은 `송찬호`. 사용자가 다른 담당자를 말하면 그 이름.
3. **저장**: Write 도구로 `data/.todo_items.json`에 배열을 쓰고 스크립트를 실행한다.
   ```bash
   node scripts/todo-add.js "송찬호" "data/.todo_items.json"
   ```
   - exit 2(동시편집 감지)면 한 번 더 실행한다.
4. **보고**: 추가된 항목을 목록으로 짧게 보여준다. "칸반보드에 없는 기업명"이 있으면 함께 알린다.
   열려 있는 웹앱은 창을 다시 클릭하면 자동으로 불러온다.

## items.json 예시

```json
[
  { "company": "삼성전자", "title": "TSP 일정확인", "due": "2026-10-01" },
  { "company": "공통", "title": "교육팀 주간회의 자료 준비" },
  { "title": "노트북 반납" }
]
```

## 주의

- 스크립트는 `todos`에 추가만 한다. 기존 할 일·교육 데이터는 수정하지 않는다.
- state.json을 Read하지 않는다. 병합은 스크립트가 한다.
