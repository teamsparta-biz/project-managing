# 오늘의 업무 정리 스킬

할 일은 칸반보드 **'내 할 일'(state.todos) 한 곳에만** 저장한다. '오늘 할 일' 패널과 Slack 메시지는 그중
**할 날(`plannedFor`)이 오늘이거나 지난 미완료 할 일**을 보여주는 화면일 뿐이다. 못 끝낸 일은 다음 날 자동으로 이월된다.

## A. 사용자가 할 일 목록을 적었을 때 (예: "내일 할 일: 기아 Autoland 운영매니저 06:00-16:00, 인건비 정리 …")

1. **정리**: 항목별로 `{company, title, time?, due?}`로 나눈다.
   - `company`: 칸반 기업명(예: `한화에어로스페이스`, `(주)넥슨코리아`, `디케이메디칼솔루션(주)`). 기업 업무가 아니면 `공통`.
   - `title`: 기업명을 뺀 할 일. 사용자가 쓴 말을 바꾸지 않는다 (줄임말·교육명 그대로).
   - `time`: 시간이 있으면 `HH:MM` 또는 `HH:MM-HH:MM`.
   - 같은 목록 안 중복(예: 앞뒤로 두 번 적은 "인건비 정리")은 하나로.
2. **날짜**: "오늘" 목록이면 오늘, "내일" 목록이면 내일(KST). "오늘 할 일과 합쳐서"라고 하면 아직 안 끝난 오늘 항목도 같은 날짜로 포함한다.
3. **미리보기**: Write로 `data/.plan_items.json`에 배열을 쓰고 먼저 `--dry-run`:
   ```bash
   node scripts/todo-plan.js "송찬호" data/.plan_items.json --date YYYY-MM-DD --dry-run
   ```
   스크립트는 같은 기업의 미완료 할 일 중 제목이 같거나 포함 관계면 그 할 일의 할 날만 바꾸고(중복 생성 안 함), 없으면 새로 만든다.
4. 양식대로 정리한 메시지(아래 C 형식)를 채팅에 보여준다. 사용자가 고치라고 하면 반영한다.
5. 확정되면 `--dry-run` 없이 실행해 저장한다. exit 2(동시편집)면 한 번 더 실행.
   - 항목을 목록에서 빼라고 하면 그 항목은 items에서 빼고, 이미 저장했다면 사용자에게 칸반 '오늘 할 일'에서 "내일"로 넘기거나 '내 할 일'의 해 버튼으로 빼도록 안내한다.

## B. 아침 정리·전송 (/daily-plan, 9시 자동 실행)

1. **초안 생성** (읽기 전용):
   ```bash
   node scripts/daily-plan.js "송찬호"
   ```
   할 날이 지정된 일이 있으면 그 목록으로 `오늘 할 일`을 만든다(이월 표시 포함). 하나도 없으면 마감 임박·체크리스트·교육 노트에서 자동으로 모은다.
   state.json을 Read하지 않는다.
2. **오늘 캘린더 확인**: `mcp__claude_ai_Google_Calendar__list_events`로 오늘 00:00~23:59 기본 캘린더 일정을 조회한다.
   - 시간이 정해진 미팅·교육은 해당 기업 항목 아래 `HH:MM 일정명`으로 넣는다. 초안에 이미 있으면 하나만 남긴다.
3. **다듬기**: 구조(섹션·순서)는 유지하고, 너무 긴 교육명만 줄인다 (예: "현대엔지비 현대자동차 연구소 기술직 전체 실무 프로젝트 교육" → "현대엔지비 기술직").
   데이터에 없는 할 일을 지어내지 않는다. 표는 쓰지 않는다 (Slack 표는 편집할 수 없다).
4. **전송**: 받는 사람은 `.claude/skills/daily-plan/config.json`의 `slackUserId`(본인 DM).
   - 인자에 `--auto`가 있으면(스케줄 실행) 바로 `mcp__claude_ai_Slack__slack_send_message`로 보낸다. 본인에게만 가는 DM이고, 사용자가 자동 전송을 요청해 둔 상태다.
   - `--auto`가 없으면 완성본을 채팅에 먼저 보여주고, 사용자가 "보내"/"전송"이라고 승인한 뒤에 보낸다. 문구가 바뀌면 다시 승인을 받는다.
5. **보고**: 전송된 메시지 링크를 알려준다.

## C. 메시지 형식

```
*11/5(목) 오늘의 업무*

*Goal & KPI*
팀/파트 목표: …
내 목표: …

*금주에 집중하는 프로젝트들과 그 이유*
- 기업 교육명
  - 이유

*오늘 할 일*
- 기업
  - 할 일
- 공통
  - 할 일
```

## 설정 (`.claude/skills/daily-plan/config.json`)

- `teamGoal`·`myGoal`: 목표 문구. "목표 바꿔줘"라고 하면 이 파일을 고친다.
- `excludeFocus`: 금주 집중 프로젝트에서 뺄 교육명 일부(예: `"TSP총괄 피플팀"`). "이거 집중 프로젝트에서 빼줘"라고 하면 여기에 추가한다.
- 자동으로 모으는 규칙(며칠 안 마감까지 넣는지 등)은 `scripts/daily-plan.js` 상단 주석에 있다.
