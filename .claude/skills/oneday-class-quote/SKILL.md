# 원데이 클래스 견적서 안내 메일 스킬

클로드 AI 원데이 클래스 **신청 시트에 새로 추가된 행**을 찾아, 신청자별로 견적서를 만들고 안내 메일 초안을 Gmail 임시보관함에 저장합니다.

- 신청 시트: `1mK12zs8GhqYB3uo_OmQ4HFr7Rv-7V1XDKJZ9q0hyeVU`
- 처리기록: `data/.oneday_class_sent.json` (이미 메일을 만든 `신청 ID` 목록)
- 견적서 양식: `.claude/skills/oneday-class-quote/` 폴더의 `견적서*.xlsx`
- 산출 견적서: `산출물/견적서/원데이클래스/`

> **핵심 원칙**
> - 처리기록에 있는 신청은 **다시 만들지 않는다**. 중복 발송 방지가 이 스킬의 존재 이유다.
> - 메일은 **임시보관함에만 저장**한다. 사용자가 "검수 완료"라고 하기 전에는 저장조차 하지 않고, 어떤 경우에도 스킬이 직접 발송하지 않는다.
> - 교육 일시·인원·금액은 **시트 값을 그대로** 쓴다. 본문 예시 문구의 값으로 덮어쓰지 않는다.

## 전체 흐름 요약

```
[1단계] 신청 시트 읽기
    ↓
[2단계] 처리기록과 비교해 신규 신청만 추림 (없으면 종료)
    ↓
[3단계] 신규 신청별로 견적서 생성 (스킬 폴더의 양식 사용)
    ↓
[4단계] 메일 초안 출력 → 사용자 검수
    ↓
[5단계] "검수 완료" 입력 시 Gmail 임시보관함 저장 + 처리기록 갱신
```

인수로 `신청 ID`나 이름을 주면 그 건만 처리합니다(처리기록에 있어도 재작성). `--dry-run`은 견적서 생성·저장·기록 갱신을 모두 생략하고 초안만 출력합니다.

## 1단계: 신청 시트 읽기

`read_file_content`로 시트를 읽습니다.

```
fileId: 1mK12zs8GhqYB3uo_OmQ4HFr7Rv-7V1XDKJZ9q0hyeVU
```

컬럼 구성 (2026-08-04 기준):

| 컬럼 | 용도 |
|---|---|
| 신청일시 | 견적서 신청일 |
| 이름 | 메일 수신자 이름 (`OOO님`) |
| 회사명 | 견적서 상호 |
| 직무 | 참고용 (메일에는 쓰지 않음) |
| 연락처 | 견적서 담당자 연락처 |
| 이메일 | **메일 수신 주소** |
| 희망수강일정 | 교육 일시 (그대로 사용) |
| 참석인원 | 수강 인원 |
| 결제금액 | 견적서 합계 금액 |
| AI사용경험 / 자동화희망업무 / 문의내용 | 참고용 (메일에는 쓰지 않음) |
| 동반 참여자 정보 | 참석인원 2명 이상일 때 견적서 참고 |
| 개인정보동의 / 동의시각 | 참고용 |
| 신청 ID | **처리기록 키** |

- `이메일`이 비어 있으면 그 행은 건너뛰고 사용자에게 알립니다.
- `개인정보동의`가 "동의"가 아니면 처리하지 않고 사용자에게 알립니다.
- 컬럼이 추가·이동되어도 **헤더 이름으로 찾습니다**. 열 순서를 가정하지 않습니다.

## 2단계: 발송 현황 표시 + 신규 신청 추리기

시트에서 읽은 모든 신청 ID의 발송 여부를 확인합니다.

```bash
python .claude/skills/oneday-class-quote/oneday_quote.py status --ids "<신청ID1,신청ID2,...>"
python .claude/skills/oneday-class-quote/oneday_quote.py filter --ids "<신청ID1,신청ID2,...>"
```

`status`는 처리기록(`data/.oneday_class_sent.json`)의 발송 시각을 JSON으로, `filter`는 미발송 ID만 출력합니다.

**먼저 전체 신청 현황 표를 반드시 출력합니다** — 어느 행이 이미 발송됐는지 사용자가 한눈에 보게 합니다.

```
| 신청일시 | 이름 | 회사명 | 인원 | 발송 여부 |
|---|---|---|---|---|
| 2026-08-04 09:32 | 우외석 | 누리앤소방전기안전 | 2 | ✅ 발송완료 (2026-08-04 10:15) |
| 2026-08-05 14:02 | 김OO | OO기업 | 1 | 🆕 미발송 |
```

- `✅ 발송완료 (발송시각)` — 처리기록에 있는 행. 다시 만들지 않습니다.
- `🆕 미발송` — 이번에 처리할 행.
- `⚠️ 건너뜀 (이메일 없음 / 개인정보 미동의)` — 처리 불가 행. 이유를 함께 적습니다.

> 발송 표시는 **스킬 출력에만** 표시됩니다. 현재 연결된 Google Drive 도구에는 시트 셀 쓰기 기능이 없어 시트 자체에 표시를 남길 수 없습니다. 시트에 직접 표시가 필요하면 사용자에게 알리고, 시트 마지막에 `발송여부` 열을 두고 수동 기록하는 방식을 제안합니다.

- 미발송이 없으면 현황 표를 보여준 뒤 **"새로 추가된 신청이 없습니다."**라고 알리고 종료합니다. 억지로 예전 건을 다시 만들지 않습니다.
- 미발송이 여러 건이면 **건별로** 견적서와 메일 초안을 만듭니다. 한 통에 여러 신청자를 묶지 않습니다.

## 3단계: 견적서 생성

스킬 폴더에서 견적서 양식을 찾습니다 (`Glob`: `.claude/skills/oneday-class-quote/견적서*.xlsx`).

현재 양식(`견적서양식.xlsx`)은 placeholder가 아니라 **실제 셀에 값이 들어 있는 서식**입니다. 채울 셀은 3곳뿐입니다.

| 셀 | 내용 | 값 |
|---|---|---|
| `C4` | 수신처 | `{회사명} {이름} 담당자 귀하` |
| `E7` | 견적일 | 오늘 날짜, **`2026년 08월 04일` 형식 문자열** (월·일 두 자리 0채움) |
| `E8` | 상단 합계금액 | 최종 견적 |
| `I12` | 수강 인원 | 시트 `참석인원` |
| `K12` | 1인 단가(**공급가**) | `결제금액 ÷ 참석인원` |
| `L12`·`L13`·`L15` | 공급 금액·합계·총합 | `인원 × 단가` |
| `L16` | VAT | 총합 × 10% |
| `L17` | 최종 견적(부가세 포함) | 총합 + VAT |

> **🚨 수식 칸도 계산된 숫자를 직접 넣어야 합니다.** 양식의 `E7`·`E8`·`L12`·`L13`·`L15`·`L16`·`L17`은 원래 수식이지만, openpyxl은 수식을 저장할 때 **계산 결과를 캐시하지 않습니다.** 수식을 그대로 두면 재계산하지 않는 뷰어(구글 드라이브 미리보기 등)에서 **총합·VAT·최종 견적·견적일이 전부 빈칸으로 보입니다** (2026-08-04 실측). 반드시 아래처럼 계산 결과를 `--cell`로 함께 넣으세요.

```bash
PYTHONIOENCODING=utf-8 python .claude/skills/oneday-class-quote/oneday_quote.py quote \
  --template ".claude/skills/oneday-class-quote/견적서양식.xlsx" \
  --out "산출물/견적서/원데이클래스/[누리앤소방전기안전] 클로드 AI 원데이 클래스 견적서.xlsx" \
  --cell C4="누리앤소방전기안전 우외석 담당자 귀하" \
  --cell E7="2026년 08월 04일" \
  --cell I12=2 --cell K12=300000 \
  --cell L12=600000 --cell L13=600000 --cell L15=600000 \
  --cell L16=60000 --cell L17=660000 --cell E8=660000
```

생성 후 `data_only=True`로 다시 읽어 `L15`·`L16`·`L17`·`E7`에 값이 들어갔는지 확인합니다.

### PDF 변환 (필수)

첨부용 최종 파일은 **PDF**입니다. xlsx를 만든 뒤 같은 폴더에 PDF를 함께 생성합니다.

```powershell
$dir = "G:\내 드라이브\Project_managing_tool\산출물\견적서\원데이클래스"
$src = Join-Path $dir "[회사명] 클로드 AI 원데이 클래스 견적서.xlsx"
$tmp = "<스크래치패드>\quote.pdf"
$dst = Join-Path $dir "[회사명] 클로드 AI 원데이 클래스 견적서.pdf"
$excel = New-Object -ComObject Excel.Application
$excel.Visible = $false; $excel.DisplayAlerts = $false
$wb = $excel.Workbooks.Open($src, $false, $true)
$wb.ExportAsFixedFormat(0, $tmp)      # 0 = PDF
$wb.Close($false); $excel.Quit()
[System.Runtime.Interopservices.Marshal]::ReleaseComObject($excel) | Out-Null
Copy-Item $tmp $dst -Force
```

- **스크래치패드에 먼저 만들고 복사합니다.** Google Drive 폴더(`G:\내 드라이브`)로 직접 `ExportAsFixedFormat`하면 0바이트가 됩니다 (2026-08-04 실측).
- 복사 직후 PowerShell `Get-Item`이 크기를 **0으로 보고해도 실패가 아닙니다** — 드라이브 동기화 지연입니다. `ls -la`로 다시 확인하세요 (정상 크기 약 164KB, 헤더 `%PDF`).
- Excel COM을 쓰므로 Excel이 설치된 PC에서만 동작합니다. 변환이 안 되면 xlsx만 안내합니다.

- 시트의 `결제금액`은 **공급가(부가세 별도)** 기준입니다 (2026-08-04 확인). 즉 2명·600,000원이면 공급가 600,000 / VAT 60,000 / 최종 견적 660,000원입니다. 단가를 부가세 포함으로 환산하지 마세요.
- `결제금액 ÷ 참석인원`이 나누어떨어지지 않으면 임의로 반올림하지 말고 사용자에게 물어봅니다.
- 양식이 `{{...}}` placeholder 방식으로 교체되면 `--cell` 대신 `--field 키=값`을 씁니다(스크립트가 둘 다 지원).
- 양식이 없으면 **견적서를 만들지 말고** "스킬 폴더에 견적서 양식(`견적서*.xlsx`)을 넣어주세요"라고 안내한 뒤, 본문 초안만 보여줍니다.
- 비고란(`C19`)의 교육 일정·인원 문구는 양식 고정값입니다. 시트 값과 다르면 사용자에게 알립니다.

## 4단계: 메일 초안 출력

**제목**: `[팀스파르타] 클로드 AI 원데이 클래스 신청 견적서 송부`

**본문**:

```
안녕하세요, {이름}님.
팀스파르타 클로드 AI 원데이 클래스 프로젝트 매니저 {발신자이름}입니다.

먼저 저희 클래스에 관심을 가져주시고, 비개발직군 직장인을 위한 '클로드 AI 원데이 클래스'에 신청해 주셔서 진심으로 감사드립니다.
작성해 주신 신청서를 바탕으로 원활한 교육 진행을 위해 견적서를 정리하여 첨부파일로 보내드립니다.
아래 내용을 확인하신 후 행정 절차 진행을 부탁드립니다.

[교육 신청 및 결제 안내]

* 교육 과정: 비개발자 직장인을 위한 클로드 AI 원데이 클래스
* 교육 일시: {교육일시}
* 교육 장소: 서울시 구로구 구로동 170-10 팀스파르타 AI 캠퍼스 교육장
* 수강 인원: {참석인원}명
* 정산 안내: 본 교육의 비용 정산은 교육이 완료된 이후 세금계산서 발행을 통해 처리될 예정입니다. 세금계산서 발행을 위해 필요한 서류(사업자등록증 등)를 미리 회신해 주시면 원활한 처리에 도움이 됩니다.

[첨부 파일 목록]

1. 교육 견적서 1부

서류 내용 중 수정이 필요하거나 정산 절차와 관련하여 추가 문의 사항이 있으시면 언제든 본 이메일의 회신 또는 010-9890-5715로 연락 주시기 바랍니다.
귀사의 AX(AI 전환) 도입을 돕는 유익한 교육이 될 수 있도록 정성껏 준비하겠습니다.

감사합니다.
{발신자이름} 팀스파르타 드림
```

**교육 일시 표기**: 시트의 `희망수강일정` 값을 그대로 쓰되 읽기 쉽게 정리합니다.
`8월 22일 토요일 종일반 (09:00~17:00 (점심 12:00~13:00))` → `2026년 8월 22일(토) 09:00~17:00(종일반, 점심 12:00~13:00)`
연도는 `신청일시`의 연도를 씁니다. 시간을 임의로 바꾸지 않습니다 — 시트가 09:00~17:00이면 09:00~17:00으로 씁니다.

**발신자 이름**: `.env`의 `USER_EMAIL`로 ax-hub `profiles.display_name`을 조회하거나, 조회가 어려우면 `송찬호`를 씁니다.

초안 출력 시 수신자 주소·첨부 파일명·신청 ID를 함께 보여주고, 아래 문구로 마무리합니다:

> **수정할 내용이 있으면 말씀해 주세요. 내용이 확인되셨으면 "검수 완료"라고 입력해 주시면 Gmail 임시보관함에 저장합니다.**

## 5단계: 임시보관함 저장 + 처리기록 갱신

사용자가 "검수 완료"를 입력하면:

1. **첨부는 사용자가 직접 합니다 — 스킬은 첨부를 시도하지 않습니다** (2026-08-04 사용자 확정).
   base64 첨부는 문자열을 도구 호출에 그대로 실어야 하는데(1자≈1.9토큰), 이 견적서는 xlsx 40KB(base64 약 54,900자)·PDF 164KB(약 219,000자)로 어느 형식이든 한도를 넘습니다. 로고를 최적화해도 들어오지 않습니다. **base64 인코딩을 시도하지 말고** 초안만 저장한 뒤 PDF 경로를 안내하세요.
2. `create_draft`로 **첨부 없이** 초안을 저장하고, 생성한 PDF 경로를 알려주며 "임시보관함에서 직접 첨부해 주세요"라고 안내합니다. 본문의 "첨부파일로 보내드립니다" 문구는 그대로 둡니다 — 사용자가 첨부 후 발송합니다.
3. 처리기록을 갱신합니다.
   ```bash
   python .claude/skills/oneday-class-quote/oneday_quote.py mark --ids "<신청ID>" --note "<이름>/<회사명>"
   ```
   저장에 **성공한 건만** 기록합니다. 실패한 건을 기록하면 다시는 메일이 만들어지지 않습니다.
4. 완료 보고:

> **✅ {이름}님({회사명}) 메일 초안이 Gmail 임시보관함에 저장되었습니다.**

| 양식에 채우지 못한 placeholder가 남음 | 어떤 placeholder인지 알리고, 사용자 확인 후 진행 |
| 이메일 주소 없음 / 개인정보 미동의 | 해당 행 건너뛰고 목록으로 안내 (처리기록에 남기지 않음) |
| base64가 30,000자 초과 | 첨부 생략, 파일 경로 안내 후 수동 첨부 요청 |
| 같은 사람이 여러 번 신청 | `신청 ID`가 다르면 별개 신청으로 처리. 중복 의심이면 사용자에게 먼저 확인 |
