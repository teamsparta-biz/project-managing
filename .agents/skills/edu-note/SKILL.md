# 교육 노트 추가 스킬

칸반보드 교육 카드마다 있는 **교육 노트**(노션 같은 상세 페이지, `company.page` 마크다운)에 사용자가 말한 내용을 정리해 추가한다.

## 실행 흐름

1. **대상 카드**: 사용자가 말한 기업명(예: "현대엔지비"). 대화에서 "지금부터 작성하는 내용은 ○○에 관한 거야"라고 정했으면, 다른 기업을 말하기 전까지 이후 내용도 같은 카드에 쓴다.
2. **정리**: 사용자가 적은 내용을 바꾸지 않고 마크다운으로만 정돈한다.
   - 주제 한 줄 → `## 제목` (예: `## 황대환 강사 교육리뷰`)
   - 하위 항목 → `- 항목`, 해야 할 일이 분명하면 `- [ ] 항목`
   - 사용자가 쓰지 않은 내용·해석을 덧붙이지 않는다.
3. **저장**: Write 도구로 `data/.page_content.md`에 쓴 뒤 실행한다.
   ```bash
   node scripts/page-add.js "송찬호" "현대엔지비" "data/.page_content.md"
   ```
   - 담당자 기본값은 `송찬호`.
   - 기존 노트 맨 아래에 이어 붙는다. 사용자가 "전체 바꿔줘"라고 하면 `--replace`.
   - 같은 이름의 카드가 여러 개라 중단되면, 출력된 목록에서 교육명으로 맞는 카드를 고르고 카드 id로 다시 실행한다. 애매하면 사용자에게 묻는다.
   - exit 2(동시편집 감지)면 한 번 더 실행한다.
4. **보고**: 어느 카드에 무엇이 추가됐는지 짧게 알린다. 열려 있는 웹앱은 창을 다시 클릭하면 자동으로 불러온다.

## 주의

- 스크립트는 해당 카드의 `page`/`pageUpdated`만 바꾼다. 다른 교육·할 일 데이터는 건드리지 않는다.
- state.json을 Read하지 않는다. 병합은 스크립트가 한다.
